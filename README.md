# StockBill – Inventory & Invoicing for Micro Sellers

A clean, modern, mobile-first web app for tracking products/stock and creating invoices.  
Designed for home bakers, WhatsApp sellers, street vendors, and small businesses in Pakistan, India, Bangladesh and beyond.

## Features

- **Dashboard** – Quick overview of products, revenue, low stock & out-of-stock items
- **Products** – Add, edit, delete products with price, stock quantity, unit and low-stock alert
- **Create Invoice** – Select products, set quantities, add customer details → stock automatically decreases
- **Invoices** – View history, share via WhatsApp, download PDF
- **Settings** – Business name, currency (PKR / INR / BDT / USD / EUR), phone number
- **Data stays on device** – Everything is stored in the browser (localStorage). No account needed.
- **Works offline** – Once loaded, you can use it without internet
- **Looks like a real mobile app** – Bottom navigation, smooth sheets, clean modern UI

## How to Use (Zero Cost)

### Option 1 – Open directly on your phone/computer
1. Unzip this folder
2. Open `index.html` in Chrome / Safari / Edge
3. On mobile: Tap the browser menu → “Add to Home Screen” for app-like experience

### Option 2 – Free hosting (recommended)
1. Create a free account on [Vercel](https://vercel.com) or [Netlify](https://netlify.com)
2. Drag & drop this entire folder
3. You get a free public link (e.g. `yourname.vercel.app`)
4. Share the link with sellers or open it on your phone

### Option 3 – GitHub Pages
1. Create a free GitHub repository
2. Upload these files
3. Enable GitHub Pages

## Important Notes
- Data is stored **only on the device/browser**. Clearing browser data will erase everything.
- Use the **Export Data** button in More → regularly to keep a backup.
- PDF generation requires an internet connection the first time (loads jsPDF library). After that it works offline.
- For best experience use Chrome or Safari on mobile.
